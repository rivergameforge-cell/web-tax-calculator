# 연봉 실수령액 계산 방법: 보험료와 소득세를 나눠 확인하는 순서

계약서의 연봉을 12로 나눈 금액과 통장 입금액이 다른 이유는 보험료와 원천징수 세금입니다. 다만 모든 공제를 한꺼번에 “세금”이라고 보면 어떤 항목에서 차이가 났는지 찾기 어렵습니다. 급여명세서를 보험료, 소득세, 지방소득세와 기타 공제로 나눠 보는 것이 출발점입니다.

이 글은 일반 직장가입자의 계산 구조를 설명합니다. 지역가입자 보험료, 사업소득 3.3%와 퇴직금은 서로 다른 규칙을 적용합니다.

## 1. 연봉과 월 지급액을 구분하기
연봉을 12로 나눌 때 정기 상여와 성과급이 포함됐는지, 퇴직급여가 별도인지 먼저 확인하세요. 성과급을 한 달에 받으면 매달 같은 금액이 지급되는 구조가 아닙니다.

비과세 식대가 연봉에 포함된 경우 월 지급액은 유지하면서 과세 대상 금액이 줄어듭니다. 적격 식대는 월 20만원 한도를 확인하며, 회사가 별도 식사를 제공하는 등 조건에 따라 비과세가 안 될 수 있습니다.

## 2. 2026년 7월 직장가입자 보험료
| 항목 | 근로자 부담 기준 |
| --- | --- |
| 국민연금 | 기준소득월액의 4.75% |
| 건강보험 | 보수월액의 3.595% |
| 장기요양보험 | 본인 부담 건강보험료의 13.14% |
| 고용보험 | 실업급여 부담 0.9% |

국민연금 기준소득월액은 2026년 7월부터 2027년 6월까지 하한 41만원·상한 659만원입니다. 건강보험에도 상한이 있습니다. 따라서 네 항목의 비율을 단순히 더한 값을 모든 급여에 그대로 적용하면 정확하지 않습니다.

과세 보수 월 300만원을 동일 보험 기준으로 가정한 원 단위 절사 모델은 국민연금 142,500원, 건강보험 107,850원, 장기요양보험 14,171원, 고용보험 27,000원입니다. 합계는 291,521원입니다. 실제 고지서의 단수 처리와 정산분은 별도입니다.

## 3. 실제 소득세는 간이세액표로 원천징수
회사의 월 원천징수는 국세청 근로소득 간이세액표와 상여 규칙을 따릅니다. 급여액, 공제 대상 가족과 자녀, 원천징수 비율 선택 등에 따라 달라집니다. 지방소득세는 소득세의 10%를 함께 원천징수합니다.

TaxCalc Korea 연봉 계산기는 간이세액표를 직접 조회하지 않습니다. 연간 근로소득공제·기본공제·연금 공제와 일부 세액공제를 적용한 연간 추정치를 12로 나누는 모델입니다. 보험료 세법상 공제·표준세액공제·특별공제와 모든 고소득자 한도를 정산하지 않으므로 실제 월 세금과 다를 수 있습니다.

## 4. 연봉별 비교 예시
2026년 10월 6일 모델 확인 결과입니다. 본인 기본공제 1명, 자녀 공제 0명, 연봉 안에 비과세 월 20만원이 포함됐다고 가정했습니다.

| 세전 연봉 | 월 실수령액 추정 |
| --- | --- |
| 30,000,000원 | 2,233,196원 |
| 40,000,000원 | 2,882,790원 |
| 50,000,000원 | 3,521,240원 |
| 60,000,000원 | 4,149,474원 |
| 70,000,000원 | 4,777,751원 |

표는 서로 다른 연봉을 동일 조건으로 비교하기 위한 것입니다. 회사의 실제 지급일·상여 배분, 가족 자격과 연말정산 자료를 대체하지 않습니다. “세후 월급이 정확히 이 금액”이라고 해석하면 안 됩니다.

## 명세서와 비교할 때 확인할 순서
1. 연봉 안의 상여·식대·퇴직금 포함 여부를 구분합니다.
2. 보험기관의 기준소득월액·보수월액과 정산분을 확인합니다.
3. 회사가 사용하는 간이세액표의 가족 수·원천징수 비율을 확인합니다.
4. 노동조합비·사우회비·대여금 등 세금이 아닌 공제를 분리합니다.

이 네 가지를 확인하면 계산기가 틀린 것인지, 애초에 입력 조건이 다른 것인지 판단하기 쉬워집니다.

## 자주 묻는 질문
### 같은 연봉인데 실수령액이 다른 이유는?
과세·비과세 급여 구성, 보험료 정산, 가족 공제, 상여 배분과 회사의 기타 공제가 다르기 때문입니다.

### 월급에서 덜 떼면 연말정산도 유리한가요?
월 원천징수액은 미리 내는 세금입니다. 연말정산의 최종 결정세액과 비교해 부족하면 추가 납부할 수 있어, 이번 달 입금액만으로 절세 여부를 판단할 수 없습니다.

### 프리랜서도 이 요율을 쓰나요?
직장가입자와 사업소득자의 구조는 다릅니다. 3.3% 원천징수는 최종 세율도 아니며 지역 건강보험료는 재산·세대 자료 등이 필요합니다.

## 기준 자료와 계산기
[국민연금공단 요율 안내](https://www.nps.or.kr/eng/ntnlpnsplan/cntb/getOHAI0013M0.do), [보건복지부 건강보험 기준](https://www.mohw.go.kr/menu.es?mid=a10705010500), [장기요양보험 기준](https://www.mohw.go.kr/menu.es?mid=a10712030100)을 함께 확인하세요.

[연봉 실수령액 계산기](https://taxcalc.co.kr/income/salary.html)로 입력 조건을 비교하고, [4대보험 계산기](https://taxcalc.co.kr/income/insurance.html)로 보험료 부분을 따로 확인할 수 있습니다.
